API research

Why these APIs suit Khetora

The APIs below were selected because they make a farming webpage more useful without making the code difficult to explain.

Geolocation API

Captures the current latitude and longitude so a future farm dashboard can use location-based weather data.

Local Storage API

Saves a farmer's basic profile in the browser so it remains available after a page refresh.

File API and Drag and Drop

Lets a farmer select or drop a crop photo and see a preview before uploading it to a real server.

Canvas API

Draws a simple crop-status chart directly in the browser from the selected soil-moisture value.

Web Notifications API

Shows a browser reminder after the user gives permission, useful for a field inspection reminder.

Audio and Video APIs

Demonstrate how Khetora can provide short learning media to farmers inside the webpage.
